Search Bars

To add a new search:
1. Enter the search term "TESTSEARCH" without the quotes into the searchbar of any website
2. Copy the full URL of the results page
3. Click the 'Add New' button on this page, and paste the copied URL into the 'Site url' field.
4. Add a name and hit 'Save'.

Browser Default Search
The first search bar uses your browser's default search engine. This is to comply with the Chrome Web Store Terms of Service.
